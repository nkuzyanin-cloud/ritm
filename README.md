# Ритм

Главный экран «Ритма» — поселение, которое растёт за последовательные отмеченные дни без вейпа. Сначала лагерь, на 3-й день первый дом, на 14-й пристань, на 30-й город. Всего 36 этапов до годового праздника. Открытые районы можно перелистывать свайпом, стрелками клавиатуры или из статистики.

Затяжка, неудачный день и полностью пропущенный календарный день прерывают серию. Следующая серия начинает строиться на пустом участке. Отметки остаются в дневнике. Газировка и вода доступны из статистики через нижнюю панель. Отметки, настройки и достижения рассчитываются из журнала на устройстве. Интернет нужен для первой загрузки. После установки сервис-воркера приложение открывается и без подключения.

## Запуск

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000. Чтобы опубликовать приложение на GitHub Pages, выберите **Settings → Pages → Deploy from a branch → main → / (root)**. Пути относительные, поэтому проект работает в подкаталоге репозитория. Для установки на iPhone откройте опубликованную страницу в Safari и добавьте её на экран «Домой» как веб-приложение.

## Данные

В настройках доступна одна JSON-копия всех трекеров. Приложение также импортирует отдельные копии трекеров из «Без пара». Перед импортом копии приложение показывает, какие записи будут заменены. У новой версии отдельный адрес, и прежние записи переносятся через экспорт и импорт.

Проверка моделей трекера и поселения: `npm test`.
